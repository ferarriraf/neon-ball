Neon Escape

A personal tool that generates original animated videos and posts them to its owner's own TikTok account.

What it does

Neon Escape renders original "ball escape" animations: a ball bounces inside rotating neon rings and breaks through them layer by layer. Every bounce plays the next note of a melody, so the animation performs the tune as it goes. Videos are rendered from code on a private server and published automatically twice a day.

How it uses TikTok

  • Login Kit (user.info.basic) — the owner signs in once with their own TikTok account to authorize the tool; the scope only confirms which account is connected.
  • Content Posting API (video.publish) — the tool posts the videos it generated to that same account, with a caption and hashtags.

There are no user accounts and no third-party users: it is a server-side script that works exclusively on its owner's own account.
