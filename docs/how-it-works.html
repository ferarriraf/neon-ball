How a video is built

Every clip goes through the same five stages. The whole run is deterministic: the same seed and the same music always produce the same video, which is what lets the soundtrack line up perfectly with the image.

  1. Pick the music

    The playlist is shuffled once when the tool starts, then played in order, so every track is used before any of them repeats. MIDI files are preferred; ordinary audio files are also accepted.

  2. Extract the melody

    A MIDI file holds several parts at once. The tool scores each channel on how high and how varied it is, discards anything too sparse to be a theme, and keeps the top note whenever several sound together. A loop hammered at the very start — a typical intro ostinato — is skipped so the recognisable tune begins straight away. The result is shifted by whole octaves into a register a phone speaker can actually reproduce.

  3. Simulate the run

    The physics runs first, with no drawing at all: gravity, damped bounces, wall friction. Each impact, each ring cleared and each sphere completed is recorded with its exact timestamp. The simulation stops on the first completed sphere past the minimum length.

  4. Build the soundtrack

    Those timestamps drive the audio. A bounce plays the next note of the melody; clearing a ring adds a chime without consuming a note; completing a sphere triggers a fanfare. Every note is synthesised with a short attack and a long decay, so the tail bridges the gap to the next bounce.

  5. Render and publish

    The same run is replayed, this time drawing each frame — neon rings, trail, sparks, spectrum analyser, title card, fades — and piping raw frames into the encoder. The finished file is uploaded through TikTok's official Content Posting API.

Inside the simulation

Bounces

The velocity is reflected around the wall normal, damped by restitution, with a little tangential friction. Nothing is scripted.

Never stuck

The bottom of a ring is a bowl. Rather than adding a fixed impulse — which would fire the ball off a side wall — the tool tops the ball's energy up to what it takes to climb back out from wherever it landed. Large at the bottom, near zero high up.

Never spinning in place

If a bounce leaves almost no sideways motion, the velocity is rotated — not increased — so at least a share of it runs along the wall.

Openings

The ball passes when its body genuinely fits through the gap, computed from its radius and the ring's, so it never bounces off empty space.

Rendering

Frames are drawn onto in-memory surfaces — the server has no display. Each neon band is a single filled polygon with an anti-aliased outline: drawn as a thick polyline instead, the joints leave notches that crawl as the ring turns and the whole circle appears to shimmer. Sparks, trail and dissolving rings are composited additively, so a fading particle adds light rather than painting dark pixels over the scene.
