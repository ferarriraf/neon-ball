The ball plays the music.

Neon Escape is a self-hosted tool that renders original “ball escape” animations from code. A ball bounces inside rotating neon rings and breaks out layer by layer — and every single bounce plays the next note of a melody, so the animation performs the tune as it goes.

It runs unattended on a private server and publishes the videos it makes to its owner's own TikTok account, twice a day.

What makes a video

A melody, not a soundtrack

The tool reads a MIDI file, isolates the lead voice and plays it one note per bounce. Nothing is sampled: each note is synthesised on the fly.

Real physics

Gravity, damped bounces and friction. Speed rises and falls naturally instead of being scripted, so no two videos ever look the same.

Layer by layer

Each ring has a rotating opening. Clearing one dissolves it into drifting motes; clearing a whole sphere sets off a shockwave and a fanfare.

Ends on a win

A clip runs past the one-minute mark and then closes on the next completed sphere, so it never cuts off mid-run.

Rendered from code

Frames are drawn headless and piped straight into an encoder — no game engine, no screen capture, no editing pass.

Hands-off publishing

Two videos a day at randomised times, posted through TikTok's official Content Posting API to the owner's own account.
